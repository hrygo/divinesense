# DivineSense v0.9.2 Release Notes

**Release Date**: 2026-02-03
**Version**: 0.9.2

---

## 🚀 New Features

### CC Runner Session Stats & Cost Tracking

完整的会话统计持久化与成本追踪系统。

#### Database Schema (PostgreSQL)

**agent_session_stats** - 完整会话追踪表
- Token 使用细分 (input/output/cache read/cache write)
- 耗时指标 (thinking/tool/generation)
- 成本追踪 (total_cost_usd)
- 工具调用和文件操作记录
- 错误状态追踪

**user_cost_settings** - 预算管理表
- 每日预算限额
- 每会话成本阈值
- 告警偏好 (email/in-app)

**agent_security_audit** - 安全审计日志表
- 风险等级追踪 (low/medium/high/critical)
- 命令模式匹配
- 操作记录

#### Backend API (5 个 RPC)

| RPC | 描述 |
|:-----|:-----|
| `GetSessionStats` | 按 session_id 查询单个会话 |
| `ListSessionStats` | 分页列出会话列表 (limit/offset) |
| `GetCostStats` | N天聚合统计及每日明细 |
| `GetUserCostSettings` | 用户预算和告警配置 |
| `SetUserCostSettings` | 更新成本控制设置 |

所有处理程序包含用户认证和所有权验证。

#### Frontend Components

- **CostTrendChart**: 可视化成本趋势，每日细分
- **SessionSummaryPanel**: 增强成本显示和统计数据
- i18n 支持成本追踪 UI (en/zh-Hans)

#### Async Persistence

**Persister**: 基于队列的后台统计持久化
- 可配置队列大小 (默认 100)
- 优雅关闭，数据丢失追踪
- 每条记录 5 秒保存超时

## 🐛 Bug Fixes

### Security Fixes
- SQL 注入修复：getDailyCostBreakdown 使用参数化查询
- 所有 QueryContext 迭代后添加 rows.Err() 检查
- 正确区分 sql.ErrNoRows 与实际错误
- MaxOffset 限制 (10000) 防止无限制分页

### Error Handling
- Persister 关闭泄漏：添加 AIService.Close() 方法
- Heartbeat panic 安全：defer close(heartbeatDone)
- GetMostExpensiveSession 添加错误日志

## ⚡ Performance Optimizations

- **parseStringArray**: O(n) 性能 (使用 strings.Builder 替代字符串拼接)
- **Partial Index**: 添加 `idx_session_stats_user_success` 针对 is_error=false 查询
- **Redundant Index**: 移除 user_cost_settings.user_id 上的冗余索引 (UNIQUE 约束已提供索引)
