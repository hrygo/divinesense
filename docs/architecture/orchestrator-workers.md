## 核心组件详解

### 1. FastRouter (快速路由器)

**职责**：基于规则和缓存的快速意图识别

| 组件 | 功能 | 延迟 |
|------|------|------|
| Cache Layer | 缓存路由决策 | ~0ms |
| Rule Matcher | 规则匹配 + 历史分析 | ~0ms |
| Confidence Evaluator | 置信度评估 (阈值: 0.8) | - |

**触发 Orchestrator 的条件**：
- 置信度 < 0.8
- 多意图关键词 ("顺便"、"同时"、"还有")
- 无法识别的意图

### 2. Orchestrator (任务编排器)

#### 2.1 Decomposer (任务分解器)

```yaml
配置文件: config/orchestrator/decomposer.yaml

输入:
  - userInput: 用户原始请求
  - expertDescriptions: 可用专家列表

处理:
  1. 理解意图 - 分析用户真正想要什么
  2. 匹配专家 - 选择最适合的专家
  3. 任务分解 - 为每个专家创建具体任务
  4. 依赖分析 - 判断并行/串行

输出: TaskPlan (JSON)
```

#### 2.2 Executor (任务执行器)

```go
// 并行执行模式
MaxConcurrency: 3  // 最大并行数
Strategy: goroutine + sync.WaitGroup

// 事件流
Events:
  - plan: 展示任务分解
  - task_start: 任务开始
  - task_end: 任务完成/失败
```

#### 2.3 Aggregator (结果聚合器)

```yaml
配置文件: config/orchestrator/aggregator.yaml

触发条件: plan.aggregate == true && tasks > 1

策略:
  - Primary: LLM 融合多源信息
  - Fallback: 简单拼接

语言支持:
  zh: "中文"
  en: "English"
```

### 3. Expert Agents (专家代理)

| 专家 | 符号 | 工具 | 策略 |
|------|------|------|------|
| MemoParrot | 📝 | memo_search | ReAct |
| ScheduleParrot | 📅 | schedule_add/query/update, find_free_time | ReAct |

## 关键设计决策

### 1. 两级路由策略

| 层级 | 组件 | 延迟 | 触发条件 |
|------|------|------|----------|
| L1 | FastRouter | ~0ms | 简单意图、高置信度 |
| L2 | Orchestrator | ~400ms | 复杂意图、多意图 |

### 2. 任务并行化

```go
// 并行执行控制
MaxConcurrency: 3
Strategy: goroutine + semaphore

// 串行执行
Strategy: sequential loop with context check
```

### 3. 降级机制

| 场景 | 降级策略 |
|------|----------|
| LLM 分解失败 | Fallback Plan (单专家) |
| LLM 聚合失败 | 简单拼接 |
| 专家不可用 | 返回空计划 |
| Orchestrator 不可用 | FastRouter 直接路由 |
